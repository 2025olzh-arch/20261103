# 자기소개 페이지

대학원 AI융합교육학과 과제로 만든 자기소개 웹페이지입니다.

- 배포 URL: (Netlify 배포 후 입력)
- 사용 기술: Vite, Vanilla JavaScript, HTML, CSS

## 실행 방법

```bash
npm install
npm run dev      # 개발 서버
npm run build    # 배포용 빌드 (dist 폴더 생성)
npm run preview  # 빌드 결과 미리보기
```

## Netlify 배포 설정

- Build command: `npm run build`
- Publish directory: `dist`
